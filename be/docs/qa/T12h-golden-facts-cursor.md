## 3. TÍNH NĂNG NỔI BẬT & ĐIỂM KHÁC BIỆT (FEATURES & USP)

- **Tính năng chính:**
  1. *Composer (AI Agent):* Giao nhiệm vụ phức tạp cho AI — AI tự đọc code, lên kế hoạch, viết nhiều file cùng lúc.
  2. *Tab Autocomplete:* Gợi ý code theo ngữ cảnh nhanh hơn GitHub Copilot (theo benchmark 2025).
  3. *Codebase Context:* AI hiểu toàn bộ codebase của dự án, không chỉ file hiện tại.
  4. *Multi-model Support:* Chọn model AI yêu thích: Claude 3.7 Sonnet, GPT-4o, Gemini, Grok, v.v.
  5. *Cursor Rules:* Định nghĩa quy tắc code riêng của team — AI luôn follow quy tắc đó.
- **USP:** Code editor AI hoàn chỉnh (fork VS Code) — không cần cài thêm extension. AI Agent có thể hoàn thành cả feature phức tạp từ prompt mô tả bằng tiếng Anh.
